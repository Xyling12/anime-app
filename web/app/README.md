# ⚠️ Это НЕ тот код, который работает на anipulsetv.ru

Каталог `web/app` — копия веб-клиента AniPulse, живущая в этом репозитории
параллельно с отдельным репозиторием **[anipulse-web](https://github.com/Xyling12/anipulse-web)**.

**Боевой сайт собирается и деплоится из `anipulse-web`, а не отсюда.**
Проверено 2026-08-29: контейнер `anipulse-web-web-1` на 5.42.99.195 собирается
из `/opt/migrated/anipulse-web/app`, куда попадает архив ветки `master`
репозитория `anipulse-web`. Ни один скрипт деплоя и ни один шаг CI на `web/app`
не ссылается.

## Чем это опасно

Копии **разошлись в обе стороны** — ни одна не является надмножеством другой.

Есть только здесь:

| Файл | Что это |
|---|---|
| `src/lib/analytics.ts` | клиент аналитики, подключён в `src/components/Providers.tsx` |
| `Dockerfile` | свой образ (в `anipulse-web` он лежит в `migration/deploy/`) |

Есть только в `anipulse-web`:

| Файл | Что это |
|---|---|
| `src/app/opengraph-image.tsx` | генерируемая OG-картинка для соцсетей |
| `src/app/{dm,friends,notifications,u/[nick]}/layout.tsx` | `noindex` на приватных разделах |
| `src/app/leaderboard/*` | раздел «Топ лидеров» |
| `public/sw.js`, `public/manifest.json` | Service Worker и PWA-манифест |
| `src/components/ShortcutsModal.tsx` | окно горячих клавиш |

Плюс десятки файлов различаются содержимым.

## Почему это важно для безопасности

Исправление уязвимости в одной копии **не защищает вторую**. Реальный пример:
29.08.2026 обновление `next` 16.2.10 → 16.3.3 (девять high-advisory: SSRF, cache
confusion, DoS) и добавление непривилегированного пользователя в Dockerfile
пришлось делать дважды — отдельно здесь и отдельно в `anipulse-web`. Если бы
вторую копию не заметили, уязвимости остались бы в ней открытыми.

## Что с этим делать

Нужно решение владельца: **какая копия каноническая**.

- Если канон — `anipulse-web` (а деплой говорит именно об этом), то отсюда стоит
  перенести `src/lib/analytics.ts` и удалить `web/app` целиком.
- Если канон — эта копия, то деплой надо переключить на неё, а `anipulse-web`
  свести к зеркалу.

Пока решение не принято, **правки вносите в `anipulse-web`** — именно он уезжает
в прод. Любая правка здесь на боевой сайт не попадает.
