# AniPulse — аудит внешних сетевых соединений

Дата проверки: 22.07.2026.

## Итог для уведомления РКН

- База AniPulse и API-шлюз находятся в российском ЦОД IXcellerate: 117545, г. Москва, ул. Подольских Курсантов, д. 15Б, стр. 1 (подтверждено поддержкой Timeweb Cloud для IP 5.42.99.195).
- APK штатно обращается к собственному домену `anipulsetv.ru`; каталог, постеры, аккаунты и социальные функции идут через российский шлюз.
- AniLibria HLS на живой пробе: `cache-rfn.libria.fun`, IP 31.184.217.238, сеть RIPE `SELECTEL-NET`, страна RU.
- Kodik HLS на живой пробе: `cloud.solodcdn.com`, IP 176.58.48.48, сеть RIPE `DIGITALONE-CDN-WORLD`, страна NL.
- Поэтому для текущей сборки нельзя без дополнительной юридической оценки утверждать, что трансграничная передача отсутствует: при воспроизведении Kodik устройство соединяется с иностранным CDN, который получает IP устройства и технические метаданные запроса.

## Прямые соединения APK

| Назначение | Домен | Результат |
|---|---|---|
| Основной API, аккаунты, чат, комментарии, OAuth callback, обновления | `anipulsetv.ru` | RU, Timeweb Cloud |
| Видео AniLibria (динамический HLS) | `cache-rfn.libria.fun` | RU на момент проверки |
| Видео Kodik (динамический HLS) | `cloud.solodcdn.com` | NL на момент проверки |
| Авторизация в системном браузере | `oauth.yandex.ru`, `login.yandex.ru`, `id.vk.com` | российские сети на момент проверки |

Динамические HLS-хосты могут меняться. Проверка одного выпуска фиксирует фактическое текущее поведение, но не является гарантией будущей географии CDN.

## Соединения российского API-шлюза

Шлюз может обращаться к `shikimori.io`, `anilibria.top`, `animego.me`, `api.jikan.moe`, `cdn.myanimelist.net`, `smotret-anime.online`, `api.aniskip.com`, `s4.anilist.co`, `graphql.anilist.co`, `kodik-api.com`, `kodikplayer.com`, `smtp.yandex.ru`, `oauth.yandex.ru`, `login.yandex.ru`, `id.vk.com`.

Часть каталогов и видеосервисов использует иностранные сети. По проверенному коду запросы каталога/видео от шлюза не содержат пользовательский токен AniPulse, email, ник или внутренний ID; внешний источник видит IP российского шлюза и параметры тайтла/серии. OAuth является отдельным добровольным потоком пользователя через VK/Яндекс.

## SDK и разрешения APK

- Firebase, Crashlytics, Sentry, OneSignal, AppsFlyer, Amplitude и рекламные SDK в зависимостях не найдены.
- Разрешения: `INTERNET`, `POST_NOTIFICATIONS`.
- Доступа к контактам, местоположению, SMS, телефону, микрофону и календарю нет.
- Незашифрованный HTTP запрещён: `android:usesCleartextTraffic="false"`.

## Варианты устранения неопределённости

1. Временно убрать Kodik из релизной сборки и оставить российский источник AniLibria; дополнительно контролировать географию его динамических CDN.
2. Проксировать HLS Kodik через российскую инфраструктуру. Это потребует проверки нагрузки, стоимости трафика, устойчивости и прав на такое проксирование.
3. Оставить прямой Kodik и до запуска получить юридическое заключение; если поток признаётся трансграничной передачей персональных данных оператором, заранее подать отдельное уведомление и актуализировать документы/согласия.

До выбора варианта форму РКН следует сохранять как черновик, не фиксируя безусловно «не осуществляется».
