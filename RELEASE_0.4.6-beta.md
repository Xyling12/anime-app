# AniPulse 0.4.6-beta

## Модерация РФ

- Из каталога, поиска, рекомендаций, календаря и деталей удалены позиции, отмеченные модерацией: Death Note, Elfen Lied, Inuyashiki и Tokyo Ghoul, включая связанные сезоны и спецвыпуски.
- Серверный шлюз фильтрует эти Shikimori ID и блокирует запросы Kodik по ним, поэтому старый APK не сможет получить эти позиции через актуальный API.
- Версия поднята до `0.4.6-beta` (`versionCode 14`).

Перед отправкой новой сборки нужно проверить APK на чистом профиле и обновить серверный gateway. Список является фильтром по выявленным модерацией позициям, а не официальной гарантией отсутствия любого контента, который может быть ограничен отдельным решением суда.

## Предрелизная проверка (27.07.2026)

Проведена перед отправкой на модерацию — все пункты пройдены:

- **Сборка**: `assembleRelease` успешна, lint — 0 ошибок (43 предупреждения, все некритичные: «доступны новые версии зависимостей»).
- **Подпись**: сертификат AniPulse (SHA-256 `4d534cc7…`), совпадает с предыдущими релизами → обновление поверх установленных копий пройдёт.
- **Версии согласованы**: build.gradle = APK = OTA-манифест = `14 / 0.4.6-beta`; APK на сервере побайтово идентичен локальной сборке (SHA-256 `6eb50f8a…`).
- **Модерация (двойной эшелон, проверено вживую)**: клиент фильтрует каталог/поиск/похожие/календарь и блокирует прямой переход (`ContentPolicy` в `AnimeRepository`), сервер отдаёт 404 на детали, режет прокси-выдачу и блокирует `kodik-dubs`. Живой тест на проде: Death Note → 404, вырезан из «популярного», поиск «Death» его не находит; разрешённые тайтлы → 200.
- **Манифест**: только `INTERNET` + `POST_NOTIFICATIONS`, `allowBackup=false`, `usesCleartextTraffic=false`, `exported` только у launcher-активити.
- **Секреты**: в трекаемых файлах и всей git-истории нет ключей/паролей (только имена свойств, читаемые из локального `keystore.properties`).
- **Серверная защита (живые тесты)**: приватные эндпоинты и запись без токена → 401; SSRF на чужой хост → 400; path traversal в `avatar-img` → 404; тело >1МБ → соединение разрывается; брутфорс логина → 429 на 6-й попытке; гейт подтверждения почты и мат-фильтр активны.
- **Инфраструктура**: сервис active, RAM 46/150 МБ, диск 41%, 0 ошибок за сутки, ежедневные бэкапы, мониторинг Kodik — OK; секретные файлы с правами 0600.
- **Живой прогон на чистом профиле** (эмулятор, релизный APK): установка → запуск → каталог → страница тайтла → плеер воспроизводит видео. 0 крэшей.

**Нюанс тестирования**: часы эмулятора отставали на 8 дней, из-за чего ExoPlayer падал на проверке TLS-сертификата CDN (`checkValidity`). После синхронизации времени видео играет. Это артефакт стенда, не дефект приложения, но стоит помнить: у пользователя со сбитыми часами воспроизведение так же не запустится.
