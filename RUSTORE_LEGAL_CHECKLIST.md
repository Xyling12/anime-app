# AniPulse Beta: юридический чек-лист RuStore

Дата подготовки: 22.07.2026. Это рабочий технический чек-лист, не индивидуальное юридическое заключение.

## Карточка приложения

- Тип: приложение.
- Основная категория: Развлечения.
- Дополнительная категория: Общение.
- Возраст текущей beta-сборки: 18+.
- Краткое описание: `Смотрите аниме, следите за новыми сериями, ставьте оценки и общайтесь`.
- Комментарий модератору: `Beta-версия для телефонов и планшетов. Интерфейс для ТВ находится в разработке. Данные тестового аккаунта указаны ниже.`
- Добавить отдельный тестовый аккаунт с подтверждённой почтой.

## Декларация данных RuStore

Отметить: имя (ник), email, ID пользователя, другие личные данные (био/жанр), фотографии (аватар), другие сообщения в приложении, взаимодействие с приложением, история поиска, другой пользовательский контент, другие действия, диагностика при добровольном баг-репорте.

Не отмечать: геолокацию, телефон, адрес, контакты телефона, календарь, финансовые и медицинские данные, микрофон/аудио, видео пользователя, список установленных приложений.

Обоснование `POST_NOTIFICATIONS`: `Разрешение используется для уведомлений о выходе новых серий, личных сообщениях, упоминаниях и заявках в друзья. Разрешение запрашивается у пользователя; приложение сохраняет основную функциональность при отказе.`

## Сведения для уведомления Роскомнадзора

Перед подачей заполнить точными данными оператора:

- ФИО/наименование и адрес оператора;
- ИНН и контакты;
- ответственный за обработку персональных данных;
- дата начала обработки;
- адрес российского дата-центра/хостинга и место базы данных;
- наличие или отсутствие трансграничной передачи;
- обработчики: хостинг, Яндекс.Почта, VK ID, Яндекс ID;
- цели: регистрация и защита аккаунта, синхронизация профиля, социальные функции, модерация, уведомления, поддержка;
- субъекты: зарегистрированные пользователи и лица, отправляющие обращения;
- категории: ник, email, идентификаторы, аватар, био, статистика, оценки, сообщения, комментарии, дружеские связи, жалобы, IP в технических журналах, данные добровольного баг-репорта;
- действия: сбор, запись, систематизация, накопление, хранение, уточнение, использование, передача обработчикам, блокирование, удаление, уничтожение;
- меры защиты: TLS, хеширование паролей scrypt, зашифрованное хранилище Android, отзыв токенов, rate limit, права файлов 0600, systemd sandbox, firewall/fail2ban, резервные копии с ограниченным доступом;
- сроки: согласно опубликованной политике конфиденциальности.

## Обязательные действия владельца

1. Заполнить `server/deploy/legal.example.json` настоящими сведениями и установить на сервер как `/opt/anipulse/legal.json` с правами `0600`.
2. Проверить итоговые страницы `/privacy`, `/terms`, `/personal-data-consent`, `/community-rules`.
3. Подать уведомление об обработке персональных данных в Роскомнадзор до публичного запуска, если применимое исключение отсутствует.
4. Назначить человека, который будет ежедневно проверять очередь жалоб и фиксировать решения.
5. Получить юридическую оценку прав на видеоконтент. Возрастная маркировка, страница правообладателям и удаление по жалобе не заменяют лицензию.
