# Указания для работы над AniPulse

## Защита данных — не трогать без явного решения

В приложении есть защитные механизмы, которые легко потерять при рефакторинге,
потому что снаружи они выглядят как лишний код. Каждый из них закрывает конкретную
угрозу; подробности и модель угроз — в [docs/ANDROID_SECURITY.md](docs/ANDROID_SECURITY.md).

**Перед изменением любого пункта ниже — спросить владельца.**

| Что | Где | Что сломается, если убрать |
|---|---|---|
| `EncryptedSharedPreferences` | `data/SettingsStore.kt` | токен авторизации ляжет на диск открытым текстом |
| Пароль базы печатный (Base64), не сырые байты | `data/SettingsStore.kt` | сырой ключ обрезается по нулевому байту на границе JNI, база не откроется |
| SQLCipher под Room | `data/db/AppDatabase.kt` | история просмотра будет читаться с устройства напрямую |
| Миграция открытых баз | `data/db/DatabaseKey.kt` | у обновившихся пользователей приложение упадёт при старте |
| Проверка подписи APK | `data/AppIntegrity.kt`, вызовы в `AnimeLibApp` и `MainActivity` | перепакованная сборка с бэкдором запустится как своя |
| `network_security_config` | `res/xml/`, ссылка в манифесте | трафик станет читаемым через подставной CA (Burp, mitmproxy) |
| `allowBackup=false`, `dataExtractionRules` | `AndroidManifest.xml` | данные уедут в облачный бэкап и на новое устройство |
| Вырезание `Log.v/d/i` в release | `proguard-rules.pro` | отладочные записи попадут в `logcat` на устройствах пользователей |
| `abiFilters` только ARM в release | `app/build.gradle.kts` | APK вырастет с 12.6 МБ до 24 МБ за счёт x86-библиотек SQLCipher |

Проверка подписи стоит в двух местах намеренно, это не дублирование: `AnimeLibApp`
гасит фоновый воркер (он ходит на сервер с токеном раз в 30 минут и пережил бы
закрытие экрана), `MainActivity` показывает причину пользователю.

## Сборка релиза

`keystore.properties` в корне проекта (в git не входит) обязан содержать
**четыре** поля подписи и пятое — `releaseCertSha256`:

```properties
storeFile=C:/Users/user/keystores/anipulse-release.jks
storePassword=...
keyAlias=anipulse
keyPassword=...
releaseCertSha256=4D:53:4C:...:AB:62
```

Без `releaseCertSha256` сборка не упадёт, но **проверка подписи молча выключится** —
это сделано, чтобы проект собирался из публичных исходников. Поэтому при заведении
нового окружения сборки первым делом проверить, что поле на месте:

```bash
keytool -list -v -keystore <keystore> -alias <alias> | grep SHA256
```

При смене ключа подписи значение обязано обновиться, иначе приложение перестанет
запускаться у всех.

## Проверки перед релизом

```bash
./gradlew test lint assembleRelease
node --test "server/tests/*.test.js"
```

Отдельно, на эмуляторе или устройстве: обновление поверх предыдущей версии.
Миграция базы срабатывает один раз и только при обновлении — на чистой установке
её не видно, поэтому поломка проходит все остальные проверки незамеченной.

## Секреты

Ни адресов боевой инфраструктуры, ни IP, ни паролей в коде и документации —
только переменные окружения и плейсхолдеры. Это проверяют
[`.githooks/pre-commit`](.githooks/pre-commit) и
[CI](.github/workflows/security.yml). Хук включается один раз:

```bash
git config core.hooksPath .githooks
```
